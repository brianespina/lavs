# LAVS Trading & Development — website

Marketing site for **LAVS Trading & Development Services Inc.** and its
linked enterprise **Cortijo de Palsabangon Farm OPC**, built with
[Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

Full project context — design system, component reference, route map,
engineering decisions, and open items pending client input — lives in
[`AGENTS.md`](./AGENTS.md) and [`docs/`](./docs/). Read that before making
changes; it's written so any agent or developer can pick this up cold.

## Commands

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
npm run preview  # serve the production build locally
```
